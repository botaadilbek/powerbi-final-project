В этом репозитории предоставлен финальный проект Power BI - интерактивный аналитический отчет для e-commerce/retail компании, столкнувшейся со снижением продаж:
-- создан многостраничный интерактивный дашборд для анализа продаж и прибыли, логистики и складов, клиентов и регионов, а также эффективности сотрудников;
-- реализованы KPI, динамика показателей, анализ категорий товаров, складов, регионов, клиентов и способов доставки с использованием интерактивных фильтров;
-- настроена навигация между страницами и интерактивные элементы с помощью bookmarks;
-- на отдельной странице сформулированы аналитические выводы по ключевым направлениям бизнеса и выявленным проблемным зонам.

Также в репозитории присутствует проект по Superstore Orders, в котором:
-- проведён анализ продаж, прибыли, категорий товаров, клиентов, регионов и способов доставки;
-- созданы KPI, интерактивные фильтры, визуализации и комбинированные графики для анализа динамики и структуры показателей;
-- реализована навигация между страницами и интерактивные представления данных с помощью bookmarks.
